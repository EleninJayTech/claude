# /dropin-update — 드롭인 문서 최신화 (승인 후 교체)

**역할 경계**: 이 스킬은 **문서 파일만** 갱신한다 — 구성 재적용(00 "학습해서 적용해줘")·적용 상태 점검(`/dropin-check`)은 하지 않는다.
**저장소 원본 안에서는 실행하지 않는다** — 현재 repo remote가 `EleninJayTech/claude`면 "여기는 원본 — `git pull` 사용"이라고 안내하고 중단.

## 1) 로컬 사본 탐색
- 프로젝트 루트·`docs/`에서 `NN_*.md`(예: `00_통합-설치.md`) 중 최상단에 `> **문서 버전: vX.Y**` 헤더가 있는 파일을 찾는다.
- 없으면: "로컬 사본 없음 — 00 재적용 시 GitHub raw 최신본이 사용되므로 갱신 불필요. 적용 상태 점검은 `/dropin-check`"로 보고하고 종료.

## 2) 최신 버전 비교
- 저장소 최신 확보: GitHub API(`https://api.github.com/repos/EleninJayTech/claude/contents/`)에서 같은 파일명의 download_url을 얻어 **헤더만** 조회(전체 다운로드는 승인 후).
- 표로 보고: `문서 | 로컬 vX.Y → 최신 vX.Z | 주요 변경`(최신 문서 버전 표에서 로컬 버전 이후 행 요약). 전부 최신이면 "최신 — 조치 불요"로 종료.

## 3) 사용자 확인 (필수 — 무단 교체 금지)
- 어떤 문서를 갱신할지 묻는다(전체/개별). 로컬 사본에 원본에 없는 수정 흔적이 보이면 경고하고 개별 확인(덮어쓰면 소실).

## 4) 교체 + 안내
- 승인된 문서만 raw에서 받아 같은 경로에 덮어쓴다. 교체 후 각 파일 버전 헤더를 다시 읽어 **증거로 보고**.
- 마지막 줄: "문서 갱신됨 — 구성에 반영하려면 00 문서로 재적용('학습해서 적용해줘', 재적용 분기가 버전 diff 안내). 적용 상태 점검은 `/dropin-check`."
