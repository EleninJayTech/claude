`$ARGUMENTS`를 저장한다. 인자가 비어 있으면 **직전 대화 내용**을 대상으로 삼는다.

루트 `CLAUDE.md`의 「기록 프로토콜」을 그대로 따른다 — 규칙 본문은 거기가 정본이다.

- 타입 판정 → **기존 파일 검색** → 추가 또는 신규 생성 → 「문서 작성 원칙」대로 재작성 → 경로 한 줄 보고.
- 타입이 애매하면 저장하지 말고 **먼저 묻는다.**
- 저장한 본문을 응답에 되풀이해 출력하지 않는다.
- 한 번에 여러 타입이 섞여 들어오면 **타입별로 나눠 저장**하고 경로를 모두 보고한다.
