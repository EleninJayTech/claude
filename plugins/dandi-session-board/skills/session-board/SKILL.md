# session-board — 같은 폴더 동시 세션 확인

훅이 세션마다 제목·브랜치·고친 파일을 `~/.claude/session-board/`에 기록하고, 같은 폴더(git 최상위)에 다른 활성 세션이 있으면 세션 시작·프롬프트 때 알린다. 다른 세션이 고친 파일을 고치려 하면 한 번 경고한다. 이 스킬은 그 보드를 필요할 때 직접 보는 입구다.

## 절차
1. 보드를 읽는다:
   ```
   node "${CLAUDE_SKILL_DIR}/board.mjs" list
   ```
2. 목록엔 이 세션도 함께 나온다 — 제목·첫 프롬프트로 자기 항목을 가린 뒤, 지금 작업과 겹치는 파일이 **다른** 세션 항목에 있으면 사용자에게 한 줄로 알리고, 이 작업을 `claude --worktree <이름>`으로 옮길지 제안한다(같은 작업 트리에서 미커밋 변경이 섞인다).
3. 관련 작업이면 그 세션이 고친 파일을 먼저 읽고 이어 간다. 직접 물어야 하면 `ListAgents`로 그 세션을 찾아 `SendMessage`로 묻는다(같은 머신의 세션끼리만 닿는다).
4. 목록에 이 세션조차 없으면 훅이 불리지 않는 것이다 — 플러그인이면 `/plugin`에서 `dandi-session-board`가 켜져 있는지, 사본이면 `~/.claude/settings.json`의 `hooks`에 `board.mjs` 항목이 있는지, 공통으로 `node --version`(18 이상)을 확인하라고 알린다.

## 지키는 것
- 보드는 **경고만 하고 막지 않는다** — 고칠지·옮길지는 사용자가 정한다.
- 보드에는 세션 제목·첫 프롬프트 앞 80자·브랜치·고친 파일 경로만 있다. 파일 내용은 없다.
- 3시간 동안 활동이 없거나 종료한 세션은 활성으로 보지 않고, 24시간 지난 기록은 다음 세션 시작 때 지워진다.
