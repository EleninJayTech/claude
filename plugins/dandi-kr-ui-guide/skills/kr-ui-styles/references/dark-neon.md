# 다크·고대비·네온 — 스타일 팩 정리본

> 출처: `source/dark-neon-report.md`(Claude 딥 리서치 산출물을 사용자가 2026-10-28 제공). 원문 절의 규칙을 옮기고 **서술어만 명령형으로** 바꿨다 — 수치는 원문 그대로, 사례 브랜드는 업종으로 바꿨다(사례는 원문이 갖는다). 원문에 없는 값은 ⟦보완⟧, 공식 조회·계산으로 덧붙인 것은 ⟦확인⟧.
> 태그: 【필수】공식 근거·계산으로 확인된 것 — 어기지 않는다 · 【기본값】미검증 관행 — 프로젝트 디자인 시스템·토큰이 있으면 그쪽이 우선 · 【조건부】해당 업종·화면에서만. kr-ui-guide `style-rules.md`와 같은 정의다.
> 이 팩은 kr-ui-guide "반드시 지키는 기준"을 바꾸지 않는다. 충돌하면 그쪽이 이긴다(아래 ⟦확인⟧ 표시는 그 적용 결과다).
> **다크 기본(dark-first) 팩**이다 — 라이트 테마의 반전이 아니라 어두운 캔버스를 전제로 설계한다. 라이트 테마가 필요하면 kr-ui-guide 기본 라이트 값을 쓰고 프라이머리만 강등한다(아래 「색」).

## 색
원문 「색」 — 서피스·텍스트 hex는 【기본값】, 대비 수치는 【필수】(⟦확인⟧ 2026-10-28 재계산 — 원문 대비 표 대부분의 출처가 미확인 URL이라 상대 휘도 공식으로 다시 구했다. 원문 9행 전부 일치).

서피스·텍스트 단계【기본값】:
| 토큰 | Hex | 역할 |
| --- | --- | --- |
| surface-deep | #0E0F10 | 뷰포트의 가장 깊은 바탕, 외부 여백 |
| surface-base | #141517 | 기본 페이지 배경, 플레이어 프레임 |
| surface-elevated | #202224 | 카드, 리스트 행, 입력창 배경 |
| surface-overlay | #2E3033 | 팝오버, 모달, 호버 배경 |
| text-primary | #FFFFFF | 헤드라인, 핵심 수치 |
| text-secondary | #C9CEDC | 본문 단락, 보조 라벨 |
| text-tertiary | #9DA5B6 | 메타데이터, 타임스탬프 |
| text-disabled | #545A69 | 비활성 텍스트, 플레이스홀더 |

면의 위계는 그림자가 아니라 서피스 명도로 만든다 — 바탕에서 팝오버로 올라갈수록 밝아진다.

프라이머리(네온)【필수 — 프로젝트별 지정】: 이 팩의 정체는 "어두운 면 위 고휘도 네온 하나"이고 특정 색이 아니다. 원문 예시값(사례 서비스의 브랜드 색 — 그대로 쓰지 않는다)으로 조건을 보면:
- 네온은 대형 배경 면·장문 텍스트에 쓰지 않는다. 토글 활성, 라이브 링, 즉각 반응이 필요한 주요 CTA에만 쓴다.
- ⟦확인⟧ 네온 면 위 글자는 **반드시 어두운 글자**: 원문 예 네온 그린 위 #0E0F10은 14.47:1, 흰 글자는 1.33:1(금지). 고르는 네온은 #0E0F10 글자와 4.5:1 이상, 바탕 #141517 위 3:1 이상(조작 요소)이어야 한다 — 원문 예 네온 그린은 바탕 위 13.78:1.
- ⟦확인⟧ 보조 강조색(원문 예 핫핑크)은 바탕 위 4.71:1로 본문 가능, 흰 글자를 얹으면 3.88:1이라 대형 텍스트(18.66px 굵게 이상)만, 어두운 글자 #0E0F10이면 4.95:1.
- 라이트 테마로 바꿀 때 네온은 흰 배경 위 약 1.3:1로 떨어지므로 딥 톤으로 강등한다. ⟦확인⟧ 원문이 든 강등 예시(딥 그린)는 흰 배경 위 2.71:1이라 **텍스트·조작 요소 모두 미달** — 강등 색은 흰 배경 4.5:1 이상으로 프로젝트가 정한다.

상태 색【기본값】:
- 라이브·치명적 경고 #E02020. ⟦확인⟧ 바탕 위 글자로는 3.83:1이라 **글자색으로 쓰지 않는다** — 배지 면으로 쓰고 흰 글자(4.78:1).
- 보조 선 틸 #027F80은 바탕 위 3.78:1 — 선·그래픽에만, 글자 불가.

시세 색【조건부 — 금융·가상자산】:
- 한국 관습(상승 빨강·하락 파랑)을 따른다. 퓨어 #FF0000과 #0000FF는 어두운 바탕에서 입체 수차로 초점이 갈려 피로를 부른다 — 중간 틴트의 코랄 레드·스카이 블루로 바꾼다. 정확한 hex는 프로젝트가 정한다.
- 브랜드 네온이 녹색이면 서구식 "녹색=상승"으로 오인될 수 있다 — 네온은 아바타 테두리·인터랙션 버튼에만 격리하고 시세 영역에 쓰지 않는다. 라이브 배지 빨강도 시세 빨강과 섞이지 않게 위치를 분리한다.
- ⟦확인⟧【필수】원문 예시 코랄 레드·스카이 블루는 바탕 #141517 위 4.92:1이지만 **카드 #202224 위 4.30:1** — 카드 위 14px 시세 숫자에는 못 쓴다. 숫자를 바탕 면에 두거나 대형 텍스트로 키우거나, 카드 위 4.5:1을 넘는 밝은 틴트를 프로젝트가 정한다.

## 레이아웃·컴포넌트
원문 「레이아웃·컴포넌트」 — 【기본값】.
- 그리드: 4pt 기본 증분, 미세 간격 2pt. 여러 데이터 패널(플레이어·채팅·호가창·주문 모듈)이 한 화면에 공존하는 데스크톱·태블릿이 기본 타깃.
- 카드를 마진으로 띄우지 않고 컨테이너 1px 경계선으로 공간을 나눈다.

| 컴포넌트 | 높이·패딩 | 라운딩 | 테두리 | 배경 | 그림자·고도 |
| --- | --- | --- | --- | --- | --- |
| 카드 | 내부 패딩 12~16px | 8px ~ 12px | 1px solid #2E3033 | #202224 | 없음, 호버 시 테두리를 프라이머리로 |
| 리스트 행 | 높이 36~44px, 좌우 8px | 4px (호버 시에만) | 행 구분선 1px solid #202224 | 투명, 호버 시 rgba(255,255,255,0.04) | 없음 |
| 프라이머리 버튼 | 높이 36px, 좌우 14px | 8px | 없음 | 프라이머리(네온), 글자 #0E0F10 | 없음, 포커스 시 네온 글로우 링 |
| 세컨더리 버튼 | 높이 36px, 좌우 14px | 8px | 1px solid #2E3033 | #2E3033 | 없음 |
| 입력창 | 높이 40px, 패딩 0 12px | 8px | 포커스 시 1.5px solid 프라이머리 | #202224 | 포커스 시 0 0 8px 프라이머리 글로우 |
| 내비게이션 바 | 높이 56~60px | 0px (상단 고정) | 하단 1px solid #202224 | rgba(20,21,23,0.85) + Blur 12px | 스크롤 시 0 4px 12px rgba(0,0,0,0.5) |
| 상태 배지 | 높이 20px, 패딩 0 6px | 4px | 없음 또는 1px solid | #E02020 또는 어두운 반투명 | 없음 |
- ⟦확인⟧【필수】1px #2E3033 경계는 바탕 위 1.38:1, 카드 면 #202224는 바탕 위 1.14:1 — **장식 경계일 뿐 조작 가능 경계(3:1)가 아니다**. 원문 입력창은 기본 상태 테두리가 투명이라 경계가 사라진다 → ⟦보완⟧ 입력창·체크박스 같은 조작 요소의 기본 경계는 1px #9DA5B6(바탕 위 7.39:1, 카드 위 6.45:1) 이상으로 둔다.
- ⟦확인⟧【필수】버튼 높이 36px·리스트 행 36px는 시각 크기다 — 모바일 터치 영역은 투명 패딩으로 **최소 44×44px**(원문 「접근성」과 같다).

## 이미지·일러스트·아이콘
원문 「이미지·일러스트·아이콘」 — 【기본값】.
- 사진·썸네일: 라이트용 사진을 그대로 두면 그 사각형만 발광한다 — 비네팅과 하단 그라데이션 마스크 `linear-gradient(180deg, rgba(20,21,23,0) 0%, #141517 100%)`를 적용한다. 썸네일 모서리 8px, 콘트라스트 10~15% 가산과 채도 소폭 상향.
- 일러스트: 평면 2D 파스텔 캐릭터를 피한다. 네온 림라이트를 반사하는 3D 글래스모피즘 오브젝트, 전기 회로·주파수 모티프의 라인 아트.
- 아이콘: 듀얼 렌더링 — 비활성은 24px 박스 기준 stroke-width 1.75px ~ 2.0px 라인, 호버·선택 시 채움(Filled)으로 바꾸고 프라이머리로 점등.

## 접근성 함정
원문 「접근성·사용성 함정」. 수치는 ⟦확인⟧ 재계산.
- 【기본값】할레이션: 어두운 환경에서 동공이 4~8mm로 커지고 난시 사용자는 밝은 글자 외곽이 번진다. 퓨어 블랙 위 퓨어 화이트(21:1)를 본문에 쓰지 않는다 — 본문은 #C9CEDC(11.61:1), 본문 명암비는 7:1 ~ 12:1 범위.
- 【기본값】글로우 남용: 14px 이하 본문에 text-shadow 글로우를 쓰지 않는다. 효과는 에셋 외곽선으로만.
- 【필수】네온 면 위 흰 글자 금지(원문 예 1.33:1) — 어두운 글자 #0E0F10.
- 【필수】데스크톱 밀도를 모바일에 옮기면 호가 버튼 터치 영역이 24~30px로 줄어든다 — 글자가 12px이어도 히트박스는 투명 패딩으로 최소 44×44px.
- 【기본값】원색 빨강·파랑을 붙여 두지 않는다(입체 수차) — 위 「시세 색」.
- 【필수】⟦확인⟧ 위 「레이아웃」의 조작 경계 3:1, 「색」의 카드 위 시세 숫자 4.30:1과 라이브 빨강 글자 3.83:1.

## 미확정
원문 「불확실·의견이 갈리는 것」과 원문 내부 충돌 — 규칙으로 쓰지 않는다. 결정이 필요하면 갈래를 보여 주고 사용자가 고른다.
- **다크 테마와 눈 피로** — 서비스 측 주장 대 의학 연구가 갈린다. 난시 사용자에게는 오히려 장벽일 수 있어 건강 기능으로 내세우지 않는다.
- **순수 블랙 #000000 대 딥 차콜 #141517** — OLED 전력 이점 대 블랙 스미어링. 이 팩의 기본은 딥 차콜이다.
- **한국 시세 관습 유지 대 글로벌(상승 초록) 전환** — 업계 제안과 국내 금융권·규제 당국의 주문 착오 우려가 맞선다. 이 팩은 한국 관습을 따른다.
- **효과 수치(체류 시간·전환율·주문 빈도)** — 원문이 미확인으로 뒀다.
- **원문 내부 충돌**: 자간을 "조인다"와 "축소 금지", 행간 "140~150%"와 표의 120~150%, 포커스 글로우 알파 0.3과 0.4, 모션 base 250~350ms와 300ms. 이 팩의 토큰은 원문 「설계 토큰 초안」 값을 따른다.
