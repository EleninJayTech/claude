# 게임 UI 기준 — 정리본 (입력 장치·터치·반복 콘텐츠·한글 텍스트·과금 화면)

> 출처: `source/game-report.md`(사용자 조사 — 한국 게임 시장 플랫폼별 UI/UX). 사례 게임의 화면·브랜드는 가져오지 않고 **원리만** 옮겼다. 원문에 없는 보완은 ⟦보완⟧으로 표시했다.
> 태그: 【필수】법령·플랫폼 공식 문서로 확인됐거나, 어기면 기능 결함(글자 잘림·조작 불가)이 되는 것 — 어기지 않는다 · 【기본값】미검증 관행 — 프로젝트 디자인 시스템·기획이 있으면 그쪽이 우선 · 【조건부】해당 플랫폼·상황에서만.
> 웹·앱 기준(`SKILL.md` 필수 기준·`ux-patterns.md`·`style-rules.md`·`checklist.md`)은 게임에도 그대로 적용된다 — 이 파일은 거기 없는 것만 보탠다. 출처가 약하거나 인용과 맞지 않은 주장은 `open-questions.md` "게임 리서치 편입 때 옮긴 항목"에 있다 — 규칙으로 쓰지 않는다.
> 효과·흥행 평가("호평", "대규모 이탈")는 원문이 모은 2차 자료라 근거로 인용하지 않는다.

## 1. 입력 장치
- 【필수】**PC판은 마우스·키보드 네이티브 조작을 준다** — 휠 스크롤·호버 정보·단축키를 제공하고, 터치용 대형 버튼 배치나 드래그로만 움직이는 스크롤을 PC판에 그대로 두지 않는다. 모바일에서 옮겨 온 화면이면 PC 해상도에서 버튼 크기·정보 밀도를 다시 잡는다.
- 【조건부: 입력 장치 2종 이상 지원】**마지막 입력 장치를 감지해 즉시 바꾼다** — 버튼 프롬프트 글리프(키 이름 ↔ 패드 버튼)와 포커스 내비게이션 규칙을 입력이 바뀌는 순간 교체한다. 섞여 보이는 상태(키보드 입력 중 패드 글리프)를 남기지 않는다.
- 【기본값】**리매핑** — 모든 창(인벤토리·지도·퀘스트 등)과 스킬 단축키를 사용자가 다시 지정할 수 있게 하고, 같은 키에 두 동작이 겹치면 저장 전에 알린다.
- 【조건부: 콘솔 패드 지원】**패드 피드백은 PC에서도 같은 패드로** — 햅틱·적응형 트리거를 PC판에서도 해당 패드로 동작하게 하되, 연결 조건(유선 USB 요구 등)을 설정 화면에 적는다. 특정 패드 전용 입력(터치패드 등)에 묶인 동작은 다른 패드·키보드용 대체 입력을 둔다.

## 2. 터치·화면 방향
- 【기본값】**태블릿은 엄지 반경으로 분산** — 양손으로 쥐는 대화면에서는 자주 누르는 액션을 화면 중앙이 아니라 양측 하단(엄지가 닿는 반경)에 둔다. 터치 영역 최소치는 `SKILL.md` 기준 4.
- 【조건부: 세로 플레이 지원】**회전해도 진행을 끊지 않는다** — 기기를 돌리면 진행 상태·카메라를 유지한 채 레이아웃만 재배치한다. 역할 분담 예: 세로 = 한 손 조작(대화·채팅·정리), 가로 = 넓은 시야(전투·탐험).

## 3. 반복 콘텐츠
- 【기본값】**반복 파밍은 한 화면 1단계로 끝낸다** — 소탕·일괄 수령처럼 결과가 정해진 반복 행동은 횟수 스테퍼·다중 확인 대신 "가능한 만큼 실행" 단일 버튼과 자동 반복 선택지로 끝낸다.
- ⟦보완⟧【필수】**유료 재화를 쓰는 일괄 실행은 예외** — 유상 구매한 재화가 소모되면 실행 전에 소모량을 보여 주고 한 번 확인받는다. 무상 행동력만 쓰는 반복은 확인을 붙이지 않는다(`SKILL.md` 기준 7 다크패턴과의 경계).

## 4. 한글 텍스트
- 【필수】**넘침·잘림 확인** — 번역문·사용자 입력(닉네임·길드명)·가장 긴 아이템 이름으로 모든 UI 박스를 확인한다. 말줄임을 쓰면 전체 문자열을 볼 방법(툴팁·길게 누르기)을 함께 둔다.
- 【필수】**엔진 폰트 에셋의 글리프 범위** — 게임 엔진용 폰트 에셋(비트맵·SDF 아틀라스 등)을 만들 때 실제로 표시될 한글이 모두 포함되는지 확인한다. 빠진 글자는 네모(□)나 대체 폰트로 깨진다. 몇 자를 넣을지(2,350자 vs 11,172자)는 `open-questions.md`의 기존 항목이다 — 사용자 입력을 받는 화면이면 부족한 쪽의 결함이 드러난다.
- 폰트 선택은 `SKILL.md` 기준 8과 `licenses.md`만 따른다 — 원문 4.2가 권장한 폰트 중 일부는 유료다(`licenses.md`).

## 5. 과금 화면
- ⟦보완⟧【필수】**확률형 아이템은 확률을 공개한다** — 유상 구매하는 아이템의 종류·효과가 우연으로 정해지면 아이템 종류와 확률을 게임 안과 누리집에 알아보기 쉽게 표시한다(국내 서비스 — 게임산업진흥법 제33조 제2항, 2024-03-22 시행. 미표시·거짓 표시는 시정 명령·형사처벌 대상). 뽑기를 다른 이름의 유료 보상권으로 포장해 우연 요소를 가리지 않는다.
- 【기본값】**과제 동선을 강요하지 않는다** — 일일 과제·로비 알림을 핵심 플레이로 가는 유일한 경로로 만들지 않는다. 과금·과제 안내는 닫을 수 있고, 닫기 버튼을 흐리게·작게 숨기지 않는다(`SKILL.md` 기준 7).
