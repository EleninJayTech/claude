# 판단 체크리스트 — 화면·컴포넌트 작성 후 자체 검증

> 출처: `source/trend-report.md` 10장(사용자 조사). 모든 항목이 '예'여야 최종 코드로 승인한다. 주제별 세부 체크리스트는 `ux-patterns.md`·`icons.md`·`color.md` 끝에 따로 있다 — 이 표는 그 위의 공통 관문이다. 터치 타깃 값은 원문의 이미지를 글자로 되살렸고, iOS 값만 ⟦보완⟧했다.
