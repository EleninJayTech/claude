## 1. 비주얼
### 권장
- 【기본값】**그리드·여백**: 8pt/4pt 배수 그리드를 기본 레이아웃으로 강제한다. 모바일 뷰포트(기준 폭 360~393px)의 좌우 여백(Gutter)은 16px 또는 20px로 고정하고, 카드 내부 패딩은 상하 16~20px, 좌우 16~20px를 적용한다.
- 【기본값】**라운딩 반경**: 버튼·텍스트 필드 10~14px · 카드·모달 다이얼로그 16~20px · 바텀시트 상단 좌우 20~24px · 칩·뱃지 6~8px 또는 완전 둥근 형태(Pill: 9999px).
- 【기본값】**색 공간**: sRGB/HSL의 채도 왜곡을 막으려면 인지적 균일 색공간(OKLCH)으로 명도를 제어한다. 명도 대비 자체는 【필수】 — 본문 텍스트와 배경 4.5:1 이상, 대형 헤드라인과 핵심 조작 컴포넌트 3:1 이상(SKILL.md 기준 1의 공식으로 계산한다).
- 【기본값】**중립색 톤**: 순수 무채색(#000000, #808080)을 쓰지 않는다. 차가운 블루-그레이 틴트가 2~5% 가미된 슬레이트 그레이(예: #191F28, #333D4B, #8B95A1, #F2F4F6)를 10단계 이상의 스케일로 구성한다 — 값은 `tokens.json` `color.base`.
- 【기본값】**모션**: 이징은 가속 구간을 짧게, 감속 구간을 길게 늘린 cubic-bezier(0.16, 1, 0.3, 1) 곡선 또는 감쇠비(Damping Ratio) 0.75~0.85의 스프링 다이내믹스를 쓴다. 지속 시간은 `tokens.json` `motion`을 쓴다 — 원문의 수치가 자리마다 달라 `open-questions.md`로 보냈다.
- 【기본값】**스켈레톤 UI**: 원형 스피너 대신 콘텐츠 레이아웃 형태를 미리 보여 주는 스켈레톤 카드를 배치한다. 배경 대비 4~7% 밝은 그레이 톤, 1.2~1.5초 주기의 무한 루프 선형 시머(Shimmer) 애니메이션을 쓴다.
### 지양
- 【기본값】과도한 스큐어모피즘·네오모피즘 — 양각·음각 효과와 명도 대비를 해치는 비기능적 음영을 쓰지 않는다.
- 【기본값】짙고 탁한 단일 레이어 그림자 — `box-shadow: 0 4px 8px rgba(0, 0, 0, 0.2)` 같은 고대비·짧은 확산 반경 그림자를 쓰지 않는다. 값은 `tokens.json` `shadow`.
- 【기본값】3색 이상의 다색 그라데이션 배경 — 복합 선형·방사형 그라데이션을 쓰지 않는다.
### 조건부
- 【조건부】**다크모드**: 증권 거래(WTS)·OTT·음원 스트리밍처럼 시각적 몰입과 야간 사용성이 필수인 서비스는 다크모드를 기본 제공한다. 상품 원색 왜곡이 치명적인 일반 이커머스·배달 플랫폼은 브랜드 의도에 따라 라이트모드 단일 화면으로 고정 운용할 수 있다.
- 【조건부】**글래스모피즘**: 스크롤되는 콘텐츠 상단에 고정되는 헤더 내비게이션 바와 플로팅 하단 액션 영역에 한해 `backdrop-filter: blur(16px~24px)`와 70~80% 알파 투명도를 허용한다.

## 2. UX 패턴
### 권장
- 【기본값】**하단 탭 바**: 탭 항목은 4개 또는 5개로 구성한다(3개는 정보 분산 저하, 6개 이상은 터치 오작동 유발). 바 높이는 홈 인디케이터 여백을 제외하고 56~64px을 유지한다.
- 【조건부】**검색 인터페이스**(콘텐츠 탐색형 — 쇼핑·배달): 상단 헤더에 44~48px 높이의 검색 인풋 필드를 고정 노출한다. 탭 시 별도 라우트 전환 없이 즉각적인 풀스크린 검색 오버레이와 함께 최근 검색어·실시간 트렌드 칩을 1-Depth로 렌더링한다.
- 【기본값】**소셜·간편 로그인 배치**: 소셜 로그인 버튼은 카카오(최상단) → 네이버 → 애플 → 토스 순서로 배치한다. 【필수】⟦확인⟧서드파티·소셜 로그인으로 주 계정을 만들면 App Store 심사 지침 4.8이 요구하는 동등한 프라이버시 옵션(이름·이메일만 수집, 이메일 비공개 가능, 광고 목적 상호작용 수집 없음)을 함께 둔다 — Sign in with Apple이 이를 충족하는 대표 선택이며 원문의 "iOS 심사 필수"는 정확히는 이 뜻이다. 【필수】PASS·통신사 SMS 인증 입력엔 `autocomplete="one-time-code"`를 준다.
- 【조건부】**원페이지 결제/주문**(커머스): 배송지 선택, 쿠폰/적립금 적용, 결제 수단 선택을 단일 뷰포트 안에 세로 스크롤로 구성하고, 화면 최하단에 높이 52~56px의 플로팅 CTA 버튼을 고정 배치한다.
- 【기본값】**바텀시트 중심 인터랙션**: 복잡한 2-Depth 이상의 드릴다운 화면 전환을 피하고, 옵션 선택·필터링·상세 내역 확인은 화면 하단에서 50~90% 높이로 올라오는 스와이프 닫기 지원 바텀시트로 처리한다(닫기 버튼은 7장 【필수】대로 병행).
- 【기본값】**팝업·배너 피로도**: 인앱 모달 팝업은 세션당 최대 1개로 제한하고, 하단에 "오늘 하루 보지 않기"(24시간 로컬 스토리지 캐싱) 체크박스를 의무 제공한다.
- 【필수】**터치 타깃**: 대화형 인터랙션 타깃은 최소 44×44px(모바일 네이티브 48×48dp) 이상을 물리적으로 확보한다 — iOS 네이티브는 44×44pt⟦보완⟧. 【기본값】인접 터치 타깃 간 최소 8px 간격을 둔다. ⟦확인⟧WCAG 2.2 자체의 최소 기준은 SC 2.5.8(AA) 24×24 CSS px, SC 2.5.5(AAA) 44×44 CSS px — 플랫폼 기준이 더 크므로 그것을 따른다.
### 지양
- 【기본값】핵심 탐색 수단으로서의 햄버거 메뉴(Side Drawer) 단독 운용 — 핵심 경로는 하단 탭과 메인 피드 숏컷으로 전면 노출한다.
- 【기본값】다단계 강제 슬라이드 온보딩 — 앱 설치 직후 4~5단계 이상의 강제 튜토리얼 대신 툴팁 기반 컨텍스트 온보딩(Contextual Onboarding)을 쓴다.
- 【기본값】초기 실행 시 시스템 권한 일괄 요청 — 위치·사진·알림·연락처 권한을 최초 진입 시 연달아 띄우지 않고, 그 권한을 실제로 쓰는 태스크 진입 시점에 개별 요청한다.
### 조건부
- 【조건부】**간편 모드(Senior Easy Mode)**(금융·공공·유틸리티): 고령층·저시력자를 위해 18px 이상의 고대비 텍스트, 2열 중심의 대형 액션 카드, 복잡한 마케팅 배너가 제거된 '간편 홈' 토글을 필수 옵션으로 제공한다.

## 3. 타이포그래피
### 권장
- 【기본값】**본문 기본 규격**: 모바일 본문(Body) 15~16px, 행간 150~160%(24~26px), 자간 -0.015em(-1.5%). 데스크톱 웹 본문 16px, 행간 160%(26px), 자간 -0.01em.
- 【기본값】**타입 스케일**: Display 1 32~36px(Bold 700)·행간 130~135%·자간 -0.025em / Title 1(헤더) 22~24px(Bold 700)·행간 140%·자간 -0.02em / Title 2(섹션 헤딩) 18~20px(SemiBold 600)·행간 145%·자간 -0.015em / Body 1(강조 본문/인풋) 16px(Medium 500 / Regular 400)·행간 150~155%·자간 -0.01em / Body 2(일반 본문) 14~15px(Regular 400)·행간 150~160%·자간 -0.005em / Caption(도움말/메타데이터) 12~13px(Regular 400)·행간 140%·자간 0em. 확정값은 `tokens.json` `typography.scale`.
- 【필수】**숫자 정렬**: 잔액, 결제 금액, 주가 등 수치가 열 단위로 정렬되는 인터페이스에는 `font-variant-numeric: tabular-nums;`를 선언한다.
- 【기본값】**웹폰트 배포**: 현대 한글 표준 2,350자 서브셋과 주요 특수문자를 포함한 WOFF2 단일 포맷을 우선 서빙한다(풀셋 여부는 `open-questions.md`). 【필수】CSS 선언에 `font-display: swap;`을 명시한다.
- 【필수】**폰트 스택**: `font-family: Pretendard, -apple-system, BlinkMacSystemFont, system-ui, Roboto, "Noto Sans KR", "Apple SD Gothic Neo", sans-serif;` — ⟦확인⟧Pretendard·Noto Sans KR은 SIL OFL(`licenses.md`).
### 지양
- 【기본값】한글 본문 행간 135% 이하 — 영문 기준(1.2~1.3배)을 한글 본문에 쓰지 않는다. 초성과 받침이 위아래 줄과 충돌한다.
- 【기본값】고딕 계열 본문의 양수 자간(Letter Spacing > 0) — 제목 강조 목적을 제외하고 쓰지 않는다.
- 【기본값】본문 굵기 Thin(100)/Light(300) — UI 본문의 최소 굵기는 Regular(400) 또는 Medium(500) 이상으로 유지한다.
### 조건부
- 【조건부】**가변 폰트**: 네트워크 트래픽 절감과 100~900 단위의 세밀한 웨이트 제어가 필요한 고밀도 반응형 웹은 `PretendardVariable.woff2` 단일 파일을 쓴다(⟦확인⟧가변 글꼴 제공은 공식 저장소가 밝힌다). 구형 인앱 브라우저 대응이 중요한 서비스는 정적 WOFF2 서브셋 패키지를 폴백으로 둔다.

폰트별 라이선스 표는 `licenses.md`.

## 4. 아이콘·일러스트·그래픽
> 아이콘 제작 세부(그리드·선 두께·라벨)는 `icons.md`가 먼저다. 선 두께는 두 자료가 다르다 — `open-questions.md`.
### 권장
- 【기본값】**아이콘 규격**: 바운딩 박스 24×24px(내부 2px 안전 마진 확보, 실질 렌더링 영역 20×20px). 선 끝·결합점은 `stroke-linecap: round; stroke-linejoin: round;`를 적용한다.
- 【기본값】**상태 분기**: 비활성/기본 상태 아이콘은 중립색 라인 아웃라인, 선택·활성 상태는 브랜드 컬러 또는 짙은 슬레이트 톤의 면 채움으로 시각 상태를 분기한다(원문의 예시 hex는 특정 브랜드 값이라 뺐다 — 값은 `tokens.json`·프로젝트 오버라이드).
- 【기본값】**3D 그래픽 범위**: 기능 안내성 설명에는 2D 단색 플랫 라인 아트를, 리워드 획득·온보딩 성공·404 오류·빈 내역(Empty State)에는 파스텔 톤 3D 아이소메트릭 그래픽을 쓴다.
- 【기본값】**배너·썸네일 비율**: 메인 롤링 프로모션 배너 약 2.3:1 ~ 2.7:1(375×140px ~ 375×160px) · 커머스 상품 썸네일 1:1 정방형(500×500px 이상 대응) · 피드 콘텐츠 썸네일 4:3 또는 16:9 와이드.
### 지양
- 【기본값】이종 아이콘 팩의 혼용 — 각진 모서리와 둥근 모서리, 두께가 다른(예: 1.5px과 2.5px) 아이콘을 한 서비스 안에서 섞지 않는다.
- 【기본값】비트맵(PNG/JPG) 아이콘 — 인터페이스 아이콘은 인라인 SVG 벡터로만 렌더링한다.
### 조건부
- 【조건부】**브랜드 캐릭터 노출**: 온보딩·대기 화면·프로모션 뷰에 제한적으로 쓰고, 송금·결제 승인 등 집중을 요하는 트랜잭션 화면에서는 노출을 차단한다. 타사 캐릭터는 참고만 하고 재현하지 않는다(`licenses.md`).

아이콘 자산 라이선스 표는 `licenses.md`.

## 5. 디지털 영상·모션 그래픽
### 권장
- 【조건부】**숏폼 규격**(숏폼을 쓰는 서비스): 종횡비 9:16 수직 풀스크린(1080×1920px) · 길이 15초 ~ 30초(최대 60초 이내) · H.264 / HEVC(H.265) MP4 기본, 스트리밍은 HLS(m3u8) 분할 전송.
- 【조건부】**숏폼 안전 영역**: 상단 120px(상태바·헤더) · 하단 220px(상품 구매 플로팅 바·자막·프로그레스 바) · 우측 64px 폭(좋아요·댓글·공유)에는 핵심 그래픽을 두지 않는다.
- 【기본값】**자막**: 인앱 비디오는 소리 없이도 맥락을 알 수 있도록 음성을 100% 자막화한다. 자막 폰트 28~36pt, 반투명 어두운 배경 박스(rgba(0,0,0,0.6)) 또는 2px 블랙 외곽선 스트로크를 쓴다.
- 【기본값】**인터페이스 모션(Lottie)**: 체크마크 완료·축하 폭죽·뱃지 획득은 Lottie JSON 벡터 애니메이션으로 만들고 총 재생 시간을 800ms ~ 1,200ms로 제한한다.
### 지양
- 【필수】**음소거 해제 자동 재생** — 인앱 비디오는 기본 음소거(`muted: true`)로 자동 재생하고 사용자의 명시적 탭으로만 사운드를 켠다. ⟦확인⟧Chrome 자동재생 정책: 음소거 자동재생은 항상 허용, 소리 있는 자동재생은 상호작용 전 차단.
- 【기본값】고용량 GIF 번들링 — 정적 이미지는 WebP, 모션은 Lottie JSON 또는 압축 MP4/WebM으로 대체한다.
### 조건부
- 【조건부】**라이브 커머스 PiP**: 방송 시청 중 상품 목록을 보거나 타 탭으로 이동할 때 화면 우측 하단(120×213px)으로 축소되어 계속 재생되는 플로팅 플레이어를 둔다.

## 6. 디자인 시스템·토큰
### 권장
- 【기본값】**토큰 3계층**: 1단계 베이스/프리미티브(원시 수치 — 예: `space-16: 16px`) · 2단계 시맨틱(디자인 의도 — 예: `fg-brand`, `bg-surface`, `text-primary`, `border-subtle`) · 3단계 컴포넌트(예: `button-primary-bg`, `bottom-sheet-handle-color`). 기본값은 `tokens.json`.
- 【기본값】**명명 규칙**: 소문자 케밥 케이스(kebab-case) 또는 닷 노테이션(dot.notation). 구조 [속성]-[타깃]-[역할]-[상태/변형](예: `color-text-neutral-weak`, `color-button-primary-hover`).
- 【기본값】**간격 스케일(8pt)**: space-1 4px(미세 인라인 보정) · space-2 8px(라벨과 인풋 간격) · space-3 12px(작은 카드 내부 패딩) · space-4 16px(표준 모바일 Gutter·카드 패딩) · space-5 20px(대형 카드 여백) · space-6 24px(섹션 내 모듈 간 간격) · space-8 32px(대형 섹션 간 간격) · space-12 48px(화면 최하단 여백·그룹 구분).
- 【기본값】**반응형 브레이크포인트**: Mobile < 768px(칼럼 4, Gutter 16~20px) · Tablet 768px ~ 1023px(칼럼 8, Gutter 24px) · Desktop 1024px ~ 1439px(칼럼 12, Gutter 32px, Max Container 1200px) · Wide Desktop ≥ 1440px(칼럼 12, Max Container 1400px).
### 지양
- 【기본값】임의의 하드코딩 수치 — `margin: 17px`, `color: #2b3341`처럼 토큰 스케일에 없는 원시 수치를 쓰지 않는다. 모든 속성은 선언된 토큰에 매핑한다.
- 【기본값】컴포넌트 변형(Variant)의 폭증 — 크기·형태·상태의 단순 조합으로 변형이 수백 개로 늘지 않게 속성을 모듈화한다.
### 조건부
- 【조건부】**멀티 브랜드·파생 테마**: 증권(WTS)·B2B 어드민처럼 한 프로덕트 안에서 색상 의미론이 다르면(예: 일반 금융의 Blue 긍정 vs 주식 시장의 Red 상승) Base 토큰은 유지한 채 Semantic 토큰 매핑 레이어만 덮어쓰는 파생 테마(Derived Theme)를 쓴다.

디자인 시스템 라이선스 표는 `licenses.md`.

## 7. 글로벌 트렌드와의 차이
### 권장
- 【조건부】**벤토 그리드의 고밀도 변형**(커머스·금융 홈): 모바일 카드 안에 아이콘 + 핵심 데이터 수치 + 뱃지(Badge) + 링크 인디케이터를 160×100px 전후의 타일 안에 압축 배치한다.
- 【조건부】**무한 피드형 홈**: 기능 아이콘 격자(Icon Grid Launcher)만 노출하지 않고, 첫 화면부터 아래로 스크롤하며 맞춤 추천 상품·혜택·실시간 피드가 이어지는 피드형 구조로 만든다.
- 사회적 증거(Social Proof) 마이크로카피는 `open-questions.md` — 다크패턴 경계.
### 지양
- 【기본값】Google Material You(Dynamic Color)의 무조건 수용 — 사용자의 배경화면 색에 따라 인터페이스 주요 색이 바뀌는 M3 동적 테마를 상업 서비스에 쓰지 않는다. 브랜드 고유 컬러를 유지한다.
- 【기본값】지나치게 넓은 공백(Negative Space) — 화면 상단 50% 이상을 한 줄 감성 카피와 빈 공간으로 두지 않는다. 첫 화면 뷰포트(Above the fold) 안에 최소 3개 이상의 구체적 실행 액션과 정보를 노출한다.
- 【필수】시각적 단서 없는 제스처 전용(Gesture-only) 조작 — 스와이프로만 닫거나 뒤로 가는 인터랙션에는 반드시 명시적인 닫기(X)·뒤로가기 버튼을 병행한다. ⟦확인⟧WCAG SC 2.5.1(A): 경로 기반 제스처 기능은 단일 포인터로도 조작 가능해야 한다.
### 조건부
- 【조건부】**생성형 AI 인터페이스**: 단일 채팅창을 화면 전체에 이식하지 않고, 하단 탭의 독립 메뉴나 기존 GUI 우측 하단의 플로팅 액션 버튼(FAB, 예: "AI 상담")로 둔다. 대화 진입 시 빈 입력창 대신 3~4개의 추천 프롬프트 칩(Prompt Chips)을 준다.
