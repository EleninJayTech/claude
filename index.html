Claude Code is Anthropic’s AI tool that develops on your own machine while you simply talk to it. The documents here are an instruction manual that executes itself — like furniture instructions that also assemble the furniture. Drop them into a folder, say “apply this”, and Claude finishes the setup. You never have to touch a config file.

Three lines to use it

Copy → say → choose

# 1. Copy 00_통합-설치.md into your working folder
# 2. Open Claude Code and say:
"Read 00_통합-설치.md and apply it to this project"
# 3. Pick an install mode — minimal / recommended / full / custom
  • “Project” here means the one folder you are working in. For a whole-machine setup, say “apply it to this PC” instead.
  • You only need to copy 00 — Claude fetches the rest from this repository when it needs them.
  • The documents are written in Korean, and that is fine. Claude executes them the same way in any language, and the installer asks which language the generated files should use — answer English and your CLAUDE.md, work logs and commit messages all come out in English.
  • Pick “recommended” and the installer inspects your project and checks the fitting combination for you. Add purpose bundles (design, stronger verification, unattended automation) for combinations like “minimal + design”.
  • If something is already installed, Claude asks whether to keep / reconcile / replace it first. Nothing is overwritten silently.
  • Not sure what a question or checkbox means? The options dictionary spells out “what gets created / when to check it / what you lose by skipping” for every item.
  • Want to learn the choices from scratch? The options course takes you chapter by chapter through a simulator you click yourself.

What the seven documents do

00 is the door · 01 is the foundation · 02–06 are reinforcement

  • 00 The unified install menu.

    Choose an install mode (minimal/recommended/full/custom) and bundles; it installs the matching subset of 01–06, each by its own procedure.

    00_통합-설치.md ↗
  • 01 Foundation — memory and safety.

    AI forgets everything when the chat closes. Document 01 builds a work-log system plus /resume (pick up where you left off), /wrap (close out the session), /dropin-check (audit your setup) and /dropin-update (refresh the documents), so yesterday’s work is still there today — and it locks passwords and key files so the AI can neither read them nor send them anywhere.

    01_Claude-Code-통합구성-범용마스터.md ↗
  • 02 Splitting work across models.

    Claude has smart-but-expensive models and fast-but-cheap ones. Document 02 assembles a small AI team that routes hard judgment to the expensive model and routine work to the cheap one — quality held, bill reduced.

    02_모델분담-범용-플레이북.md ↗
  • 03 Convenience add-ons.

    claude-hud (a live meter of how much AI you have used today) · svg-design (the graphics technique behind the yellow animation above) · frontend-design (Anthropic’s official design guidance for UI that doesn’t look AI-generated — this page was built with it) · MCP (connecting external tools) · browser verification (the AI opens the screens it built and checks them).

    03_확장기능-설치-체크리스트.md ↗
  • 04 The automatic inspector.

    Checkers run every time the AI edits code, and once more before code is merged. Instead of the AI saying “done”, you get proof the checks passed.

    04_검증-자동화.md ↗
  • 05 Changing tone and role.

    Reshape how answers come out — explanation-first, diagram-first, learning mode. Coding ability stays; only the style changes.

    05_출력스타일.md ↗
  • 06 Scheduled runs.

    Work runs in the cloud at set times even while your machine is off — nightly code review, weekly doc checks. Requires the Pro plan or above, and company code only after approval.

    06_루틴-자동화.md ↗

After install, every day

The daily routine is two commands

# Starting up — load yesterday's state
/resume ← the AI reports first: "last time you got this far, next is this, right?"
# While working — ask for the verification too
"Fix the login screen. Then verify it actually works"
# Wrapping up — write today into the log
/wrap ← today's work and decisions are recorded automatically
  • Those records are what let you resume tomorrow. You have to commit after recording for them to be found the next day — Claude walks you through it.
  • If the AI keeps spinning: run /clear when you switch to unrelated work, and if the same problem survives two fix attempts, /clear and ask again from scratch — that is usually faster.

Frequently asked

The questions everyone has at first

What is Claude Code?

An AI development tool from Anthropic. Say "build me a program that does this" as if you were chatting, and the AI creates and edits files directly on your machine. The documents in this repository configure that tool to run more safely and more capably.

Can I use it without a development background?

Yes. Dropping the files into a folder and saying one sentence is the whole job; Claude asks you about the rest as it goes. Hit a term you don't know and you can just ask Claude to "explain it simply".

Why are the documents all plain markdown?

Because they exist for Claude to read and execute, not for people. The human-facing guides are kept separately: this page plus the intro, walkthrough, options dictionary and options course in the pages/ folder. That is also why the markdown stays Korean — Claude executes it identically either way, and the install asks separately which language your generated files should use.

Can I trust the content?

Every technical claim records the date it was checked against Anthropic's official documentation, and the whole set is re-checked every six months.

Are passwords and secrets safe?

Installing 01 locks passwords, certificates and key files so the AI can neither read them nor upload them. The underlying principle still holds, though: real secrets do not belong in your working folder.

The founding principleOutput quality comes first. Saving tokens is second, and only within what quality allows.
