Claude Code is Anthropic’s AI tool that develops on your own machine while you simply talk to it. The documents here are an instruction manual that executes itself — like furniture instructions that also assemble the furniture. Drop them into a folder, say “apply this”, and Claude finishes the setup. You never have to touch a config file.

Three lines to use it

Copy → say → choose

# 1. Copy 00_통합-설치.md into your working folder
# 2. Open Claude Code and say:
"Read 00_통합-설치.md and apply it to this project"
# 3. Pick an install mode — minimal / recommended / full / custom
  • “Project” here means the one folder you are working in. For a whole-machine setup, say “apply it to this PC” instead.
  • You only need to copy 00 — Claude fetches the rest from this repository when it needs them.
  • The documents are written in Korean, and that is fine. Claude executes them the same way in any language, and the installer asks which language the generated files should use — answer English and your CLAUDE.md, work logs and commit messages all come out in English.
  • Pick “recommended” and the installer inspects your project and checks the fitting combination for you. Add purpose bundles (design, stronger verification, unattended automation and more) for combinations like “minimal + design”.
  • If something is already installed, Claude asks whether to keep / reconcile / replace it first. Nothing is overwritten silently.
  • Changed your mind later? Run 00 again and it asks both what to add and what to remove. Removing takes out only what the install created — the work logs you have built up stay.
  • On a PC you have already set up, installing into a new project starts with a quick path — pick This PC’s defaults / Same as another project / Recommended mode / One by one and the common questions (mode, bundles, operating profile and so on) are answered in one go. The values it will carry over are shown for you to confirm, and safety questions such as overwriting or company policy still appear.
  • Each choice on the install screen comes with a plain one-line note: what you get if you pick it, and what happens if you don’t (for pick-one questions, when to pick it). For more detail, the options dictionary spells out “what gets created / when to check it / what you lose by skipping” for every item.
  • Want to learn the choices from scratch? The options course takes you chapter by chapter through a simulator you click yourself.
  • Wondering what the installed skills actually do? The skill catalog explains every one — what each does, when to call it, and where it bites.

What the seven documents do

00 is the door · 01 is the foundation · 02–06 are reinforcement

  • 00 The unified install menu.

    Choose an install mode (minimal/recommended/full/custom) and bundles; it installs the matching subset of 01–06, each by its own procedure.

    00_통합-설치.md ↗
  • 01 Foundation — memory and safety.

    AI forgets everything when the chat closes. Document 01 builds a work-log system plus /resume (pick up where you left off), /wrap (close out the session), /dropin-check (audit your setup), /dropin-update (refresh the documents) and /dropin-apply (re-apply the setup), so yesterday’s work is still there today — and it locks passwords and key files so the AI can neither read them nor send them anywhere.

    01_Claude-Code-통합구성-범용마스터.md ↗
  • 02 Splitting work across models.

    Claude has smart-but-expensive models and fast-but-cheap ones. Document 02 assembles a small AI team that routes hard judgment to the expensive model and routine work to the cheap one — quality held, bill reduced.

    02_모델분담-범용-플레이북.md ↗
  • 03 Convenience add-ons.

    claude-hud (a live meter of how much AI you have used today) · svg-design (the graphics technique behind the yellow animation above) · frontend-design (Anthropic’s official design guidance for UI that doesn’t look AI-generated — this page was built with it) · MCP (connecting external tools) · browser verification (the AI opens the screens it built and checks them) · feature-doc skill set (a spec per feature, plus tests, a commit guard and release notes built on it) · refactor (clean the code up and prove the behaviour did not change) · kr-ui-guide (designs and checks UI/UX, icons and colour for Korean-audience web, app and game screens against research on Korean services). Pick frontend-design or kr-ui-guide and the installer also asks for a font licence policy — freely usable fonts only, or be told the terms first and decide each time (or leave it out) — and writes your answer into the setup so it holds whenever fonts are added or swapped.

    03_확장기능-설치-체크리스트.md ↗
  • 04 The automatic inspector.

    Checkers run every time the AI edits code, and once more before code is merged. Instead of the AI saying “done”, you get proof the checks passed.

    04_검증-자동화.md ↗
  • 05 Changing tone and role.

    Reshape how answers come out — explanation-first, diagram-first, learning mode. Coding ability stays; only the style changes.

    05_출력스타일.md ↗
  • 06 Scheduled runs.

    Work runs in the cloud at set times even while your machine is off — nightly code review, weekly doc checks. Requires the Pro plan or above and a GitHub repository, and company code only after approval.

    06_루틴-자동화.md ↗

After install, every day

The daily routine is two commands

# Starting up — load yesterday's state
/resume ← the AI reports first: "last time you got this far, next is this, right?"
# While working — ask for the verification too
"Fix the login screen. Then verify it actually works"
# Wrapping up — write today into the log
/wrap ← today's work and decisions are recorded automatically
  • Those records are what let you resume tomorrow. You have to commit after recording for them to be found the next day — Claude walks you through it.
  • If the AI keeps spinning: run /clear when you switch to unrelated work, and if the same problem survives two fix attempts, /clear and ask again from scratch — that is usually faster.
  • Don’t run two Claude sessions in the same folder at once — their unsaved changes get mixed together. Open the second task with claude --worktree <name> instead.

Keeping it up to date

Three commands, three different questions

The documents keep changing, and so do the skills they install. Which command you need depends on what you actually want moved.

# Has anything fallen behind? (reads only, changes nothing)
/dropin-check
# Refresh my copies of the documents — the instructions themselves
/dropin-update
# Bring the configuration itself up to date — documents, skills, settings
/dropin-apply ← this is the one that actually changes your setup
  • /dropin-update alone is not an update. It refreshes the instructions, not the thing the instructions build. Your installed skills and settings stay exactly as they were until you run /dropin-apply.
  • On a machine that has never been set up, /dropin-apply is also the first-install command — you do not have to know which case you are in. If the command is not there yet, just say: "read 00_핸합-설치.md from the repository and apply it to this machine".
  • A skill can change without gaining a single file. That is why the install steps compare file contents, not just file names — a revision that only reworded things still reaches your disk.

Every one of these is explained in full in the skill catalog.

Frequently asked

The questions everyone has at first

What is Claude Code?

An AI development tool from Anthropic. Say "build me a program that does this" as if you were chatting, and the AI creates and edits files directly on your machine. The documents in this repository configure that tool to run more safely and more capably.

Can I use it without a development background?

Yes. Dropping the files into a folder and saying one sentence is the whole job; Claude asks you about the rest as it goes. Hit a term you don't know and you can just ask Claude to "explain it simply".

Why are the documents all plain markdown?

Because they exist for Claude to read and execute, not for people. The human-facing guides are kept separately: this page plus the intro, walkthrough, options dictionary and options course and skill catalog in the pages/ folder. That is also why the markdown stays Korean — Claude executes it identically either way, and the install asks separately which language your generated files should use.

Can I trust the content?

Every technical claim records the date it was checked against Anthropic's official documentation, and the whole set is re-checked every six months.

Can I get just the skills, without the install documents?

Yes, for the feature-docs set, refactor and kr-ui-guide: they are also published as Claude Code plugins in the dandi marketplace — /plugin marketplace add EleninJayTech/claude, then /plugin install dandi-refactor@dandi (or dandi-feature-docs, dandi-kr-ui-guide). Use one route per skill; both at once shows every skill twice. If the installer finds one of these plugins already turned on, it asks whether to keep the plugin (and skip the copy) or replace it (remove the plugin, then copy). Details in the README.

Are passwords and secrets safe?

Installing 01 locks passwords, certificates and key files so the AI can neither read them nor upload them. The underlying principle still holds, though: real secrets do not belong in your working folder.

The founding principleOutput quality comes first. Saving tokens is second, and only within what quality allows.
