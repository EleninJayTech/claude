Claude Code는 컴퓨터에서 대화하듯 개발을 시킬 수 있는 AI 도구입니다(Anthropic 제작). 이곳의 문서들은 그 Claude Code를 내 컴퓨터에 맞게 세팅해 주는 "말로 실행되는 설명서"입니다 — 가구 설명서를 읽고 조립까지 해 주는 로봇처럼, 문서를 폴더에 넣고 "적용해줘"라고 말하면 Claude가 알아서 준비를 끝냅니다. 설정 파일을 몰라도 됩니다.

이 그림 자체가 03 문서의 svg-design 스킬 레시피(Gooey 필터 feColorMatrix 19 -8 + Squiggle 손그림 떨림)로 그린 것입니다. 설치하면 Claude가 이런 것을 만들어 줍니다.

사용법은 세 줄입니다

복사한다 → 말한다 → 고른다

# 1. 00_통합-설치.md 파일을 내 작업 폴더에 복사해 넣고
# 2. Claude Code를 켜서 이렇게 말합니다:
"00_통합-설치.md 를 학습해서 이 프로젝트에 적용해줘"
# 3. 설치 모드를 고르면 끝 — 최소 / 권장 / 전체 / 사용자(직접 선택)
  • 여기서 "프로젝트"란 지금 작업 중인 폴더 하나를 말합니다. 컴퓨터 전체에 세팅하려면 "이 PC에 적용해줘"라고 말하면 됩니다.
  • 파일은 00 하나만 복사해도 됩니다 — 나머지 문서는 필요할 때 Claude가 인터넷(이 저장소)에서 가져옵니다.
  • "권장"을 고르면 프로젝트를 조사한 결과에 맞는 조합이 자동으로 골라집니다. 목적 번들(디자인·검증 강화·무인 자동화 등)을 얹어 "최소 + 디자인"처럼 조합할 수도 있습니다.
  • 이미 설치된 것이 있으면 Claude가 그대로 둘지 / 고칠지 / 새로 깔지를 먼저 물어봅니다. 말없이 덮어쓰지 않습니다.
  • 설치 중에 나오는 질문·체크 항목이 무슨 뜻인지 모르겠다면 설치 옵션 사전을 보세요 — 항목마다 "생기는 파일 / 체크할 때 / 뺄 때"를 풀어 뒀습니다.
  • 선택지를 처음부터 차근차근 익히고 싶다면 설치 옵션 학습 코스 — 챕터 순서대로, 시뮬레이터를 직접 눌러 보면서 배우는 인터랙티브 코스입니다.

문서 일곱 장이 하는 일

00은 입구 · 01은 기반 · 02~06은 강화

  • 00 통합 설치 메뉴.

    설치 모드(최소/권장/전체/사용자)와 번들만 고르면, 01~06 중 맞는 조합을 각 문서의 절차대로 설치합니다.

    00_통합-설치.md ↗
  • 01 기반 공사 — 기억과 안전.

    AI는 원래 대화를 끄면 다 잊습니다. 01은 작업 일지 시스템과 /resume(이어하기)·/wrap(마무리 기록) 명령을 만들어 어제 하던 일을 오늘도 기억하게 하고, 비밀번호·열쇠 파일을 AI가 읽거나 밖으로 내보내지 못하게 잠급니다.

    01_통합구성-범용마스터.md ↗
  • 02 AI 역할 분담.

    Claude에는 똑똑하지만 비싼 모델과 빠르고 싼 모델이 있습니다. 02는 어려운 판단은 비싼 모델에게, 단순 작업은 싼 모델에게 맡기는 작은 AI 팀을 꾸립니다. 품질은 지키고 요금은 줄입니다.

    02_모델분담-범용-플레이북.md ↗
  • 03 편의 기능 셋.

    claude-hud(오늘 AI를 얼마나 썼는지 화면에 실시간 표시) · svg-design(이 페이지 위쪽 노란 애니메이션을 그린 그래픽 기술) · frontend-design("AI가 만든 티" 안 나는 세련된 화면을 만드는 Anthropic 공식 디자인 지침 — 이 페이지도 이걸로 만들었습니다) · MCP(외부 도구 연결) · 브라우저 검증(만든 화면을 AI가 직접 열어 확인).

    03_확장기능-설치-체크리스트.md ↗
  • 04 자동 검사원.

    AI가 코드를 고칠 때마다 검사기가 자동으로 돌고, 코드를 합치기 전에 한 번 더 검사합니다. "됐다"는 말 대신 검사 통과 증거를 받게 됩니다.

    04_검증-자동화.md ↗
  • 05 말투·역할 바꾸기.

    답변 방식을 원하는 대로 바꿉니다 — 설명 위주, 다이어그램 먼저, 학습 모드 등. 코딩 실력은 유지한 채 스타일만 바뀝니다.

    05_출력스타일.md ↗
  • 06 자동 실행 예약.

    내 컴퓨터가 꺼져 있어도 클라우드에서 정해진 시간에 AI가 알아서 작업합니다 — 야간 코드 검토, 주간 문서 점검 등. Pro 요금제 이상이 필요하고, 회사 코드는 승인을 받은 뒤에만 씁니다.

    06_루틴-자동화.md ↗

하루 루틴은 명령 두 개

# 시작할 때 — 어제 상태 불러오기
/resume ← "지난번엔 여기까지 했고, 다음은 이거죠?" 하고 AI가 먼저 보고
# 일할 때 — 확인 방법까지 같이 요청
"로그인 화면 고쳐줘. 고친 다음 제대로 되는지 확인까지 해줘"
# 끝낼 때 — 오늘 일을 일지에 기록
/wrap ← 오늘 한 일·결정이 자동으로 기록됨
  • 기록 덕분에 내일 다시 켜도 이어서 할 수 있습니다. 기록 후 저장(커밋)까지 해야 다음 날 찾습니다 — Claude가 방법을 안내합니다.
  • AI가 자꾸 헛돌면: 다른 일로 넘어갈 때 /clear(대화 초기화), 같은 문제를 두 번 고쳐줘도 안 되면 역시 /clear 후 새로 요청하는 게 빠릅니다.

자주 묻는 것

처음 보면 궁금한 것들

Claude Code가 뭔가요?

Anthropic이 만든 AI 개발 도구입니다. 채팅하듯 "이런 프로그램 만들어줘"라고 말하면 AI가 내 컴퓨터에서 직접 파일을 만들고 고칩니다. 이 저장소의 문서들은 그 도구를 더 안전하고 똑똑하게 쓰도록 세팅해 주는 것입니다.

개발을 몰라도 쓸 수 있나요?

네. 문서를 폴더에 넣고 한 문장 말하는 게 전부이고, 나머지는 Claude가 물어보면서 진행합니다. 모르는 용어가 나오면 Claude에게 "쉽게 설명해줘"라고 하면 됩니다.

문서가 왜 전부 md(텍스트 파일)인가요?

사람이 아니라 Claude가 읽고 실행하는 용도라서입니다. 사람이 읽는 안내는 이 페이지와 소개 영상·설치 시연·옵션 사전·학습 코스 네 장(pages/ 폴더)으로 따로 둡니다.

내용을 믿어도 되나요?

문서의 모든 기술 내용은 Anthropic 공식 설명서를 그날 직접 확인한 날짜와 함께 기록되고, 6개월마다 다시 점검합니다.

비밀번호 같은 건 안전한가요?

01을 설치하면 비밀번호·인증서·열쇠 파일을 AI가 읽지도, 인터넷에 올리지도 못하게 잠급니다. 그래도 근본 원칙은 "진짜 비밀은 작업 폴더에 두지 않기"입니다.

이 저장소의 기본 원칙1순위는 최적의 결과물입니다. 토큰 절약은 품질을 해치지 않는 범위의 2순위입니다.
