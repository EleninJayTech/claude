# 단디 — Claude Code 구성 문서 저장소

> [English](README.md) · **한국어**

> **단디**(Dandi)는 "제대로, 빈틈없이"라는 경상도 말입니다. 이 문서들의 약속이 그것입니다 — 감지 → 설치 → 검증, 그리고 언제나 되돌릴 수 있게.

> **Claude Code**는 채팅하듯 말하면 AI가 내 컴퓨터에서 직접 개발을 해 주는 도구입니다(Anthropic 제작).
> 단디의 문서들은 그 Claude Code를 **내 컴퓨터·내 작업 폴더에 맞게 자동으로 세팅해 주는 "말로 실행되는 설명서"** 입니다.
> 가구 설명서를 읽고 조립까지 해 주는 로봇처럼 — 문서를 넣고 한 문장 말하면 준비가 끝납니다.

## 사용법 (세 줄)

```text
1. 00_통합-설치.md 파일을 내 작업 폴더에 복사해 넣는다
2. Claude Code를 켜고 말한다:
   "00_통합-설치.md 를 학습해서 이 프로젝트에 적용해줘"
   (컴퓨터 전체 세팅이면: "... 이 PC에 적용해줘")
3. 설치 모드를 고른다 — 최소 / 권장 / 전체 중 하나면 끝
   (하나하나 직접 고르고 싶으면 "사용자" 모드)
```

- 파일은 **00 하나만** 복사해도 됩니다. 나머지는 Claude가 이 저장소에서 알아서 가져옵니다.
- **"권장"을 고르면** 프로젝트를 조사한 결과에 맞는 조합이 자동으로 골라집니다. 목적 **번들**(디자인·검증 강화·무인 자동화 등)을 얹어 "최소 + 디자인"처럼 조합할 수도 있습니다.
- 이미 설치된 것이 있으면 **그대로 둘지 / 고칠지 / 새로 깔지**를 먼저 물어봅니다. 말없이 덮어쓰지 않습니다. 나중에 00을 다시 적용하면(01을 깔았다면 `/dropin-apply` 한 번으로도) **더 깔 것**뿐 아니라 **뺄 것**도 물어봅니다 — 빼면 설치가 만든 것만 지우고, 그동안 쌓인 작업 기록은 그대로 둡니다.
- 이미 세팅해 둔 PC에서 **새 프로젝트**에 깔면 맨 앞에 **빠른 경로**가 나옵니다 — 이 PC 기본값으로 / 다른 프로젝트와 같게 / 권장 모드로 / 하나씩 고르기 중 하나로 모드·번들·운용 프로필 같은 공통 질문을 한 번에 답합니다. 가져올 값은 먼저 보여 주고 확인을 받으며, 안전 질문(덮어쓰기·회사 정책)은 그대로 나옵니다.
- **팀·여러 저장소 환경도 지원합니다** — 팀원마다 설치 위치가 달라도(상위 폴더에서 vs 개별 저장소에서) 서로 충돌하지 않고, 개인 폴더 안에 회사 저장소가 섞인 묶음이면 **저장소마다 따로** 확인합니다. 팀과 공유되는 설정(커밋)과 나에게만 적용되는 설정도 구분해서 물어봅니다.
- **Pro 요금제(사용량이 적은 요금제)라면** 설치 중 "운용 프로필"에서 **절약**을 고르세요 — 품질이 중요한 순간(어려운 판단·최종 검사)은 그대로 두고, 평상시 소비만 줄이도록 구성됩니다. 설치 후 **직접 할 것**이 하나 있습니다 — 평소 작업은 `/model sonnet`으로 시작하고(한 번 바꾸면 저장됩니다), 리뷰처럼 품질이 중요한 작업은 `claude --model opus`처럼 상위 모델로 **새 세션**을 열어 합니다.
- 설치 중에 나오는 질문·체크 항목의 뜻은 [**설치 옵션 사전**](pages/options.html)에 항목별로 정리돼 있습니다. 처음부터 차근차근 배우고 싶다면 [**설치 옵션 학습 코스**](pages/learn.html) — 시뮬레이터를 직접 눌러 보면서 익힙니다.
- 모르는 용어가 나오면 Claude에게 "쉽게 설명해줘"라고 하면 됩니다.

## 스킬을 플러그인으로 받기

설치 문서가 복사해 주는 스킬(기능 문서 세트·refactor·kr-ui-guide)은 Claude Code 플러그인 마켓 **`dandi`**로도 받을 수 있습니다.

```text
/plugin marketplace add EleninJayTech/claude
/plugin install dandi-feature-docs@dandi      # 그 밖에 dandi-refactor@dandi, dandi-kr-ui-guide@dandi
```

- 플러그인 스킬은 앞에 플러그인 이름을 붙여 부릅니다 — `/dandi-feature-docs:feature-test`.
- **스킬마다 한 경로만 쓰세요** — 설치 문서로 깔든 플러그인으로 깔든 하나만. 둘 다 있으면 같은 스킬이 두 번 보입니다. 설치 문서가 플러그인이 이미 켜져 있는 걸 찾으면 플러그인 유지(복사 설치 건너뜀)와 복사본으로 교체 중 하나를 묻습니다.
- 서드파티 마켓은 자동 업데이트가 기본으로 꺼져 있습니다. `/plugin` → Marketplaces에서 켜세요.
- 라이선스: MIT.
- 팀원마다 어느 경로를 썼는지는 이 문서 체계가 추적하지 않습니다(드롭인 설치는 기록되지만 플러그인 설치는 아닙니다) — 로컬에서 `claude plugin list`로 확인하세요.

## 단디의 원칙

- **결과물의 품질이 1순위.** AI 사용료(토큰) 절약은 2순위입니다 — 다만 강도를 더 준다고 결과가 나아지지 않는 자리에서는 싼 쪽이 타협이 아니라 그냥 정답입니다.
- **기억이 아니라 확인.** 문서의 모든 기술 내용은 Anthropic 공식 설명서를 그날 직접 확인한 날짜와 함께 기록하고, 6개월마다 다시 점검합니다.
- **어디서나 똑같이.** 특정 프로젝트나 특정 컴퓨터에서만 되는 내용은 넣지 않습니다. 문서는 환경을 먼저 감지하고 그다음 만듭니다.
- **언제나 되돌릴 수 있게.** 지우는 절차가 없는 설치 항목은 넣지 않습니다 — 되돌릴 수 없는 설치는 애초에 선택지를 준 것이 아닙니다. 기존 설정도 말없이 덮지 않고 유지·재구성·교체를 묻습니다.
- **받은 것만으로 충분하게.** 이 공개 저장소만 가진 사람도 개발 이력을 전부 가진 사람과 같은 결과를 얻습니다.
- **대화가 끝나도 작업은 이어지게.** 무엇을 했고 왜 그렇게 정했는지가 파일로 남아, 다음 세션이 기억이 아니라 기록에서 이어받습니다.
- **입문자가 혼자서도 도달하게.** 설치 중 만나는 선택지는 전부 입문자 눈높이로 설명합니다(영문·한국어).

**단디가 하지 않는 것** — 코드가 아니고(문서 전용, 빌드·테스트 없음), Claude Code를 대체하거나 감싸지 않으며(공식 기능을 어떻게 조합할지만 정하고 공식 문서가 정본인 자리는 그쪽에 맡깁니다), 모든 기능을 다 깔지도 않습니다(필요한 것만 고릅니다).
