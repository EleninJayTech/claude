대상 폴더의 `{{TODO_FILE}}`를 다룬다. 줄 형식과 상태값은 루트 `CLAUDE.md`의 「할일 관리」가 정본이다.

| `$ARGUMENTS` | 할 일 |
| --- | --- |
| (없음) | `할일`·`진행중`·`보류`를 상태별로 묶어 보여준다. `완료`는 목록에서 빼고 건수만 한 줄로 덧붙인다 |
| 상태 이름 하나 | 그 상태만 보여준다 |
| `추가 <내용>` | 새 줄을 추가한다. 상태는 `[할일]`, 등록일은 오늘. 내용에 기한·프로젝트가 있으면 필드로 넣는다 |
| `완료 <키워드>` | 그 키워드로 찾은 줄의 대괄호를 `[완료]`로 바꾼다. **여러 줄이 맞으면 고르게 한다** |
| `보류 <키워드>` / `진행중 <키워드>` | 같은 방식으로 상태만 바꾼다 |
| 그 밖 | 무엇을 원하는지 묻는다 |

- 기한이 오늘보다 지난 항목은 목록 끝에 **"기한 지남"**으로 따로 모아 보여준다.
- 상태를 바꿀 때 **대괄호 안 단어만 교체**한다. 줄을 지웠다 다시 쓰지 않는다. 고치면 frontmatter `updated`도 오늘로 바꾼다.
- `[완료]`가 20줄을 넘으면 `{{ARCHIVE_DIR}}/완료-YYYY.md`로 옮길지 묻는다.
