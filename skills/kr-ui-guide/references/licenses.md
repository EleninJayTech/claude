## 법적 유의사항 (원문 8장 2절 — 뉴스·판례 요약이며 법률 자문이 아니다)
- **폰트 파일**: 한글 글자체(도안) 자체는 저작물로 인정되지 않으나, 디지털 폰트 파일(.ttf, .otf)은 컴퓨터프로그램저작물로 보호된다. 라이선스가 없는 상용 폰트 파일을 웹·앱 패키지에 포함해 배포하면 저작권법 위반으로 민·형사 청구 대상이 된다. 앱 번들에는 SIL OFL 등 허용 라이선스 서체만 넣는다.
- **UI 표절(부정경쟁방지법)**: UI 화면 배치는 아이디어로 분류돼 저작권 침해가 기각되는 경우가 많았으나, 법원은 부정경쟁방지법 제2조 제1호 파목(성과물 무단 도용)으로 타인이 상당한 투자·노력으로 만든 독창적 UI 구성·기능 플로우의 무단 차용을 위법으로 본 판결을 내리고 있다. 경쟁 서비스의 고유 레이아웃·인터랙션 시퀀스·컴포넌트 배치를 1:1로 모방하지 않고 구조·스타일 차별화를 확보한다.
- **생성형 AI 산출물**: 문화체육관광부·한국저작권위원회 안내에 따르면 사람의 창작적 개입 없이 프롬프트만으로 생성된 이미지는 저작물로 인정되지 않아 등록이 불가능하고, 학습 원저작물의 스타일·구도 침해 리스크가 있다. 메인 비주얼·브랜드 캐릭터·로고에 순수 AI 생성 이미지를 원본 그대로 쓰지 않고, 디자이너의 실질적 2차 수정을 거쳐 배포한다.
