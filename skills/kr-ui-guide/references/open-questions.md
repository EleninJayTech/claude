# 미확정 항목 — 규칙으로 쓰지 않는다

> 출처: `source/trend-report.md` 11장(원문이 "의견이 갈린다"고 둔 것) + 편입 때 옮긴 것(출처가 약하거나, 원문 안에서 수치가 충돌하거나, 공식 조회 결과와 어긋난 것 — 2026-09-15). 해당 결정이 나오면 사용자에게 갈래를 보여 주고 고르게 한다. 확인되면 `style-rules.md`·`licenses.md`로 올린다.

## 원문 11장 — 의견이 갈리는 항목
- **이커머스/배달 도메인의 다크모드 도입 여부** — 찬성: OS 다크모드 동기화로 야간 피로 감소·OLED 배터리 절감·테크 이미지. 유보(현재 상업 이커머스 다수 채택 [추정]): 음식·패션 상품 색 왜곡 방지, 붉은 할인율·프로모션 배너 시인성 통제를 위해 라이트 단일 테마 고정.
- **한글 웹폰트 서브셋 용량(2,350자 vs 11,172자 풀셋)** — 2,350자: 초기 렌더링(LCP)·모바일 데이터 절감(용량 200~300KB). 동적 풀셋: 신조어·인명·외래어 표기(예: '눞', '쉑')가 깨져 시스템 고딕으로 폴백되는 결함 방지를 위해 유니코드 레인지 기반 동적 청크 서브셋.
- **생성형 AI 대화형 인터페이스의 주류화 여부** — 대화형 중심론: 계층형 메뉴를 해체하고 자연어 단일 창으로 탐색·주문 완결. GUI 보조 수단론(현재 국내 우세 [추정]): 시각 비교·1-Click 필터·카테고리 뷰에 익숙하고 타이핑을 피로로 인지해 챗봇은 플로팅 버튼·CS 보조에 머문다.

## 편입 때 옮긴 항목 — 검증 필요
- **마이크로 인터랙션 지속 시간** — 원문 1장 본문 150~200ms, 표 150~250ms, 관행 열 200ms ease-out로 서로 다르다. `tokens.json` `motion`은 9장 초안(150/250/350ms)을 그대로 뒀다.
- **아이콘 선 두께** — 이 원문 4장은 1.75~2.0px, 기존 `icons.md`(아이콘 리서치)는 1.5~1.6px. 결정 전까지 `icons.md`를 따른다(사례 근거가 있는 쪽).
- **사회적 증거 마이크로카피**("3,482명이 방금 신청했어요", "마감까지 03:15:20 남음", "최대 5.5% 혜택받기") — 원문 7장 권장이나 SKILL.md 기준 7(다크패턴 금지)과 경계에 있다. 실제 데이터일 때만, 조작·가공 수치는 금지.
- **"애플 로그인 iOS 심사 필수"** — App Store 심사 지침 4.8(2026-09-15 조회)은 서드파티 로그인 사용 시 **동등한 프라이버시 옵션**을 요구하며 Sign in with Apple 자체를 지목하지 않는다. `style-rules.md` 2장에는 확인값으로 적었다.
- **KRDS "법제화"·라이선스** — 원문 6장은 KRDS를 "국가 표준 UI 지침으로 법제화"라 하나 사이트는 준수 기준·가이드라인으로 표현하며, 라이선스는 '공공누리 1유형'의 근거 각주가 무관 문서였다. 저작권정책 페이지 직접 확인 전까지 [검증 필요].
- **원스토어 모바일고딕·Line SDS 라이선스** — 공식 저장소를 찾지 못했다. 기본 제외.
- **타입 스케일 `headline` 17px** — 9장 토큰에만 있고 3장 본문 스케일에는 없다.
- **1장 수치의 출처** — 그리드·라운딩·그림자 수치 대부분의 근거가 비공식 정리 사이트다(OKLCH·중립색은 서비스 기술 블로그 1차 출처). 【기본값】으로만 둔 이유다.
- **접근성 지침 명칭** — 원문은 KWCAG 2.2를 근거로 들지만 각주는 WCAG 2.2 비공식 번역본이다. `style-rules.md`엔 W3C 원문의 SC 번호로 적었다.
